
This project is part of my Masters thesis project. I have deployed a fine-tuned Llama 3.2 1B on my android phone.
This way the chatbot can run totally on the mobile phone without having to connect to the internet.
This is just a start to a plethora of applications like creating your own therapist (because personal data needs to be secure) and also this is the start of my journey in learning how to deploy ML models and optimizing them for mobile phones with limited computation power.

<img width="641" alt="image" src="https://github.com/user-attachments/assets/bb50a515-2a6e-4f60-a090-877431d4f48b" />

The above image is a high-level overview of the entire project.
The "MLC Package Loaded to Android APK" is generated by the MLC LLM framework whose model files (tokenizer and weights) have been fine-tuned and confiigured to be excuted by the TVM Runtime. 

This project also includes performance metrics measured using Android Studio profiler and Snapdragon Profiler to measure CPU, GPU and Memory utilization. 
To get a indepth data of different processors` and GPU's performance please read this paper https://arxiv.org/pdf/2410.03613.
